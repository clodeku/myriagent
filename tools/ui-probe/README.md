# 介面探針（tools/ui-probe）

以 Playwright（本機 Chrome 的 `channel:'chrome'`、無頭、暫存設定檔，不必下載瀏覽器）把 `src/Myriagent/Web/` 的網頁放進假的宿主或假的伺服器，截圖並檢查網頁↔宿主協定（`docs/web-protocol.md`）。只碰暫存設定檔、頁內的假物件與 `out*/` 資料夾：不連任何真的伺服器、不執行任何 CLI、不碰這台電腦真的剪貼簿與通知。

```bash
cd tools/ui-probe
npm install
node --test rules.test.mjs live-rules.test.mjs accountrules.test.mjs monitorrules.test.mjs gitrules.test.mjs errorrules.test.mjs searchrules.test.mjs launchrules.test.mjs drawerrules.test.mjs sendrules.test.mjs viewerrules.test.mjs settingsrules.test.mjs tabdragrules.test.mjs   # 網頁純規則（不開瀏覽器）
node probe.mjs                                  # 桌面：模擬 WebView2 宿主（含 sync-settings.mjs 的同步設定頁、monitor-probe.mjs 的電腦狀態面板），輸出 out/
node probe.mjs --monitor --only 1440            # 只跑電腦狀態面板（約 40 秒）
node probe.mjs --dash --only 1440               # 只跑儀表板帳戶卡的欄數（一排最多三張）與 HUD 動態（約 1 分鐘）
node probe.mjs --git --only 1440                # 只跑對話標頭的 git 晶片（徽章、選單、窄窗格、深淺色對比；約 20 秒）
node probe.mjs --search                         # 只跑側欄的對話搜尋（標題與內容、片段、重搜、深淺色對比；約 15 秒）
node probe.mjs --login                          # 只跑登入到期（側欄帳戶卡的標示與點擊、只留圖示、卡片提示、儀表板的一行與「重新登入」、深淺色對比）
node probe.mjs --acct-name --only 1440          # 只跑側欄帳戶名稱的跑馬燈（放不下才捲、只動 transform、滑過卡片照常捲並重算距離、改短不捲；減少動態與關掉動態效果照舊「…」；截圖 acct-marquee-dark.png；約 15 秒）
node probe.mjs --flash --only 1440              # 只跑側欄點對話時標題列的閃爍（三個窗格、點擊／Enter／右鍵開啟、連點重閃、減少動態與關掉動態效果改成靜態標示；約 30 秒）
node probe.mjs --health --only 1440             # 只跑儀表板的健康度（帳戶卡的一行、明細、電腦層級的指示檔、用代理合併／精簡；約 15 秒）
node probe.mjs --mcp --only 1440                # 只跑儀表板的 MCP（Claude 帳戶卡的一行、明細、授權與重新連線、重新檢查；約 10 秒）
node probe.mjs --schedules --only 1440          # 只跑排程頁（排程鈕與失敗數、篩選、時間軸、快速操作、交給代理、設定頁的自動診斷、深淺色；約 15 秒）
node probe.mjs --codex                         # Codex 目標、技能、速度、原生審查與壓縮入口，含深淺色與窄視窗（約 10 秒）
node probe.mjs --claudeopt --only 1440          # 只跑 Claude 對話的選項與操作（主代理與輸出風格、目標晶片、取消插入、背景工作的詳細與停止、回溯、子代理用量、等額度重置、快取提醒；約 20 秒）
node probe.mjs --fork --only 1440               # 只跑延伸成新對話（選單、旁邊的新窗格、提示樣式、失敗不留空窗格、窗格滿了；約 10 秒）
node probe.mjs --side-tabs --only 1440          # 只跑分頁放左側（版面還原、直排、上下拖曳排序、拖曳把手調寬度與夾住、雙擊恢復、鍵盤調整、切換與記住、太窄時改回橫排、分割沿用；約 15 秒）
node probe.mjs --pane-zoom --only 1440          # 只跑點了暫時放大窗格（2×2 拉長、換一格、點外面恢復、分頁列不放大、選單不算外面、只有一列時加寬；約 15 秒）
node probe.mjs --context                        # 只跑輸入框的上下文用量提示（圓環、嚴重度、說明、窄窗格、淺色對比；約 15 秒）
node probe.mjs --fx --only 1440                 # 只跑對話框的視覺效果（fx-probe.mjs：靜態裝飾、一次性動畫、減少動態與關掉動態效果時不播；約 1 分鐘）
node probe.mjs --launch                         # 只跑標題列裡的執行列（按鈕與快捷鍵、建置失敗的輸出面板、目標選單、執行模式、窄窗格與寬度掃描、淺色對比；約 40 秒）
node probe.mjs --sending                        # 只跑送出中（宿主回傳使用者訊息之前先畫在對話欄、換掉、沒有送出時的標示與按鈕、逾時、插入、排隊、輸入區的「繼續」鈕；約 15 秒）
node probe.mjs --settings --only 1440           # 只跑設定對話框（settings-probe.mjs：左側分類與頁首、窄視窗的橫排、模型設定的代理子分頁、搜尋、深淺色對比；約 30 秒）
node probe.mjs --account                        # 只跑執行中換帳戶（選單、三個按鈕的選擇框、等這一輪結束的晶片標記與取消、立即換不帶 when、窄螢幕換行；截圖 account-running-*.png）
node probe.mjs --shell                          # 只跑殼層互動（runShell：檔案抽屜的雙擊與鍵盤、選單焦點、側欄連點只開啟不改名、按著時清單重排照樣切過去、改名中重排；約 20 秒）
node probe.mjs --perf                           # 只跑介面的持續耗用（perf-probe.mjs：主執行緒忙碌比例、瀏覽器各程序的 CPU、動非合成屬性的無限循環動畫；約 2 分鐘）
MYRIAGENT_PROBE_WEB=<舊版 Web 資料夾> node probe.mjs --perf   # 前後比較：用 git archive 取出的舊版網頁量同一組情境
node remote-probe.mjs                           # 伺服器模式（第 3 階段的儀表板與連線），輸出 out-remote/
node live-probe.mjs                             # 網頁即時檢視（WP4.6），輸出 out/live/
node conv-probe.mjs                             # 伺服器渲染的項目與 XSS 語料放進桌面與瀏覽器的 DOM（WP4.2，WP4.6 擴充到聊天窗格），輸出 out-conv/
node conv-probe.mjs --control                   # 陽性對照：另放一個沒有淨化的對話，檢查都要抓到它（抓到時結束碼 0）
node --test filelinks.test.mjs && node filelinks-probe.mjs   # 回覆中的本機檔案連結：桌面另存／開啟／燈箱、網頁 fileFetch 下載與燈箱預覽，輸出 out/filelinks/
```

`probe.mjs` 開頭清掉整個 `out/`（含 `out/live/`），所以 `probe.mjs` 與 `live-probe.mjs` 不要同時跑；其他各自只清自己的資料夾。`conv-probe.mjs` 和 `tools/hub-e2e` 的工具共用序列化鎖（`../hub-e2e/lock.mjs`）。改到網頁（`src/Myriagent/Web/**`）或 `src/MyriagentHub/wwwroot/` 時，這幾支都要過（另見根目錄 `CLAUDE.md`）。

- 每個檢查印「[通過]／[失敗] 名稱 詳情」；最後另加 `liveCspNoViolations`（所有頁面 CSP 0 違規，SEC-06）與 `liveNoConsoleErrors`（主控台沒有預期以外的錯誤；情境以 `app.expect(pattern, why)` 登記預期的）。結果先寫 `out/live/live-report.json` 再關瀏覽器（關閉有時限），截圖也在 `out/live/`。結束碼：全部通過 0、有失敗 1、探針本身出錯 2。
- 檢查名稱的前綴：`harness*`（探針本身：兩種頁面、`onCmd`、各種開關真的有效）、`th*`（傳輸層：`post` 回 commandId、合成的 `commandResult`、`openConversationIds`、媒體連結開新分頁）、`hub*`（瀏覽器版：開對話、版面還原、每則 `init` 重新 `open`、閘門、卡片的 `requestDigest`、選電腦與草稿、`replacedBy`、通知、剪貼簿、換版、上傳與附件晶片、資料夾挑選、`fileRef`、長工作、截圖）、`desktop*`（桌面：副本唯讀、同步政策、設定頁的同步區、紀錄與回收區、副本的媒體）。
- 伺服器模式頁（`hub-page.mjs` 的 `openHub`）：伺服器版的 CSP（`HUB_CSP` 和 `SecurityHeaderRules.ContentSecurityPolicy` 逐字相同，`tests/MyriagentHub.Tests/Web/LiveProbeCspTests` 把關）、`fake-signalr.mjs` 的假 hub（`onCmd(name, fn)`：某個指令的結果與之後推的訊息）、`FakeApi` 的擁有者端點（上傳 `PUT /api/v1/uploads/{id}` 照 E4 回 201／200／409，可固定回 413、507；記下方法與 `X-Myriagent-Csrf`）、`/m/`、`/t/`、`/f/` 的替身。
- 桌面模式頁（`openDesktop`）：最小的 WebView2 模擬、桌面的 CSP；`/media`、`/thumb` 與副本的 `/m/`、`/t/`。live-probe 裡的 `desktopHost` 是通用的桌面假宿主（open、改政策重送標頭、`syncSetPolicy`、紀錄分頁、匯出、回收區）。
- 每個頁面最早執行的 `probeInit`（CDP 注入，不受 CSP 影響）：CSP 違規收集、可控的 `navigator.onLine`／`document.hidden`／`document.hasFocus`、`Date.now` 的推進（只推 `Date.now`：Playwright 的 `clock` 會連 SignalR 的 30 秒伺服器逾時一起觸發）、`window.open` 記錄、假的 `Notification` 與 `navigator.clipboard`（權限可控、每次呼叫都記下；無頭 Chrome 的真權限與使用者手勢不穩定，所以不用 `grantPermissions`）、`localStorage`／`sessionStorage` 可以改成丟例外、XSS 計數（`alert`／`confirm`／`prompt`／`print`）、傳輸層訊息的記錄訂閱者（`window.__probeMsgs`；`lightMessages` 只記 type 與 id，量長工作時不複製大訊息）。
- 長工作（`hubLongTasks`，S6）：80 項、約 1 MB 的對話，PerformanceObserver 的 longtask（>50 ms）瀏覽器版不比桌面多。桌面的基線要在頁面自己的工作裡送達（`sendInPageTask`，像 WebView2 的 message 事件）：DevTools 協定驅動的 `page.evaluate` 那個工作 Long Tasks API 看不到。
- 合併前審查的回歸（SCENARIOS 最後一段，拿掉對應的修正都會紅，突變驗證是 `tools/probes/wp4.6/review_mutations.py --web`）：`hubCardGateUnlistedOnLoad`（清單外的對話第一次載入，卡片照標頭的電腦停用）、`hubOlderStaleIgnored`（`loadOlder` 之後先到整份 `conversation`、`beforeId` 不是這一次的舊頁不收）、`hubUnsolicitedConversationAfterClose`（剛關掉的分頁不被主動重送重開）、`hubCardTextsKeptOnReload`、`hubCardInputBlocksBuildReload`（卡片的說明欄與問卷選項）、`hubListFilesUnknownOnReinit`、`hubFileFetchUnknownOnReinit`（重新 `init` 後不再一直轉圈）、`desktopReplicaTabRunning`（副本分頁照 `header.replica` 轉圈）、`hubUploadCancel`（×、關分頁、`conversationClosed` 都中止 `PUT`，以頁內的 `XMLHttpRequest.abort` 計數驗）、`hubFileSearchDraft`、`hubFileSearchRejected`（「@」搜尋不能用時說明、Enter 照常送出）、`hubDirsPickerCrumbsScope`（挑選器範圍外的上層麵包屑停用）。
- 注意：以 `context.route` 攔截時上傳進度一律是 0%，檢查不依賴百分比；網頁存版面有 300 ms 防抖、「已複製」1.4 秒後回到「複製」，相關檢查都等條件成立而不是固定等待。
