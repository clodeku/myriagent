# 使用說明

這份文件介紹 Clode Myriagent 的主要功能與操作。安裝見 [install.md](install.md)，多電腦同步與網頁版見 [hub-setup.md](hub-setup.md)。

頂端的檢視鈕可以切換**對話**、**儀表板**與**排程**三頁；右上角的齒輪是**設定**。

## 1. 帳戶

### 預設帳戶與新增帳戶

- 第一次開啟時，app 會自動加入這台電腦原本已登入的帳戶，稱為「預設帳戶」：Claude（`~\.claude`）、Codex（`~\.codex`）、Grok（`~\.grok`），以及 Antigravity。app 直接沿用原本的設定資料夾，不會搬移。
- 在儀表板按「新增帳戶」，選擇代理種類，可以新增任意多個**隔離帳戶**。每個隔離帳戶有自己的設定資料夾（`%LOCALAPPDATA%\Myriagent\accounts\{帳戶}\`），登入憑證與 CLI 紀錄互不影響。適合同時用工作與個人兩個訂閱。
- 登入方式：
  - **Claude**：在 app 內開瀏覽器授權。手機或遠端登入時，可以把授權碼貼回網頁。
  - **Codex**：在 app 內完成 ChatGPT 登入，也可以用裝置碼登入（用手機核准）。
  - **Grok**：在 app 內以瀏覽器完成 grok.com 的裝置碼登入。
  - **Antigravity**：只有一個帳戶，登入存在 Windows 認證管理員；app 會開 `agy` 的視窗讓你登入。
- 帳戶卡的「⋯」選單可以改名、改代表色、排序、切換精簡模式、登出，或移除帳戶（可以一併刪除該帳戶的設定資料夾）。

### 共用設定

隔離帳戶預設會和預設帳戶共用 CLAUDE.md／AGENTS.md 這類全域指示、skills、agents、commands、記憶與 MCP 伺服器，登入憑證則一律不共用。在「設定 → 對話」打開「跨四家 CLI 共用技能與全域指示」，還可以讓 Claude、Codex、Antigravity、Grok 四家的全域指示與 skills 雙向同步；同步前會先備份原檔。

## 2. 儀表板

- 每個帳戶一張卡：5 小時、每週、各模型每週等額度窗的圓環、7 天走勢、重置倒數、額外點數餘額，以及開著、執行中、等你回應的對話數。
- 上方摘要：帳戶數、執行中的對話、等你回應的對話、接近上限的帳戶、最近一次重置。
- 用量在對話執行中即時更新，閒置時定期查詢。資料過時時，圓環會變灰，並標出資料的年紀。
- **CLI**（「設定 → CLI」）：每個 CLI 的版本、最新版、安裝方式；可以一鍵更新、自動更新或安裝。CLI 換版之後，閒置的對話立刻改用新版；執行中的對話會在安全點以新版重開並自動接續，不重做已完成的步驟。
- **健康度**：檢查每次對話都會載入的全域指示、記憶索引、skills、MCP 與外掛有沒有太大。有問題的項目可以按「用代理精簡」，app 會開一個預先填好說明的對話草稿，由你確認後送出。

## 3. 對話

### 開始對話

按「新對話」（或側欄的 ＋），選帳戶、模型與工作資料夾後輸入訊息。Enter 送出，Shift+Enter 換行（可以在設定改成 Ctrl+Enter 送出）。

輸入區的工具：

| 項目 | 說明 |
|---|---|
| 迴紋針、拖放、貼上 | 附加圖片、影片、文件與截圖。圖片會自動縮圖給模型；影片在有 ffmpeg 時會擷取畫面 |
| `@` | 提到工作資料夾裡的檔案；也可以提到另一個已登入的 AI 帳戶，把工作委派給它（見下方「委派」） |
| `/` | 斜線指令選單（各 CLI 的指令與 skills） |
| 權限模式（Shift+Tab） | **每步詢問**：每個工具都要核准；**自動接受編輯**：只有指令要核准；**規劃**：先提出計畫，你同意才動手；**完全自動**：不再詢問（只在信任的資料夾用） |
| 模型、推理強度 | 執行中也可以換，換了會套用到這一輪 |
| 麥克風 | 語音訊息：錄音後以本機的 faster-whisper 轉成逐字稿。代理收到的是逐字稿，回覆前會先複誦 |

### 執行中

- **插入訊息**：執行中送出的訊息，Claude 與 Codex 會直接插進這一輪；其他代理則排進佇列，等這一輪結束再送。佇列存在磁碟上，當機或重開機也不會遺失。
- **停止**：按停止鈕，或在佇列裡取消某一則。
- **問卷與核准**：代理提問會顯示成選擇題；工具要核准時可以允許、這個對話都允許，或拒絕並告訴代理改怎麼做。規劃模式的計畫要你確認才會開始執行。
- **背景程式**：代理另開、在這一輪結束後還在跑的程式（例如開發伺服器），會列在標頭的「背景程式」，可以從那裡停止；程式自己結束時會在對話加一則提示。
- **燈號**：輸入框下方顯示這個對話的運行、資料、網路、硬碟燈號與 CPU 波形，都是真實的量測值。

### 版面

- 分頁＋並排窗格（最多 4 欄 × 3 排），可以拖曳分頁、分割窗格，或彈出成獨立視窗。
- 再開一次 app 會開新視窗（同一個程式）。分頁可以拖到另一個視窗；拖到視窗外，就會開一個新視窗。
- 關掉分頁時對話照樣在背景執行，可以從側欄重新打開。
- 側欄可以依帳戶、工作區與電腦篩選，也可以搜尋所有對話的標題與內容。

### 對話選單（「⋯」）

| 項目 | 說明 |
|---|---|
| 重新命名／自動命名 | 自動命名會請代理以一句話為對話取標題 |
| 換帳戶 | 換到同一種或不同種的代理。執行中可以選「現在換」或「目前步驟完成後換」；換到不同種代理時，新的一方會收到前文節錄 |
| 延伸成新對話 | 複製目前的內容，由新的代理在旁邊的窗格接著做，兩邊各做不同的事 |
| 回溯（Claude） | 回到某一則訊息之前，對話與檔案都還原，再重新來過 |
| 工作資料夾 | 選擇、最近使用、恢復預設；可以用檔案總管開啟 |
| 匯入 | 從側欄匯入你在終端機或 IDE 用 CLI 開過的歷史對話，匯入後可以直接接著做 |
| 刪除 | 刪除對話時，可以一併停止它另開的背景程式 |

### 委派給其他 AI 帳戶

在 Claude Code 或 Codex 的對話輸入 `@`，從清單選一個已登入的 AI 帳戶，再寫要交辦的工作，例如「請這個 Codex 帳戶檢查測試，你負責修正」。主 AI 會建立一個子對話交給那個帳戶執行（共用同一個工作資料夾），等它完成後整合結果。你可以從對話清單查看子對話的過程、回答它的問卷與核准。

### 工作資料夾的 git 與執行列

- 標題列的 git 晶片顯示分支、未提交的變更、未推送與未拉取的提交數。有未拉取的提交、而且沒有衝突風險時，會自動快轉拉取。
- 工作資料夾裡有 .NET 視窗程式（WinExe）或 Electron 專案時，標題列會出現執行列：建置並執行、暫停、停止、重新建置並執行，並可以展開輸出面板。**Debug** 模式的程式跟著 app 一起關閉；**Release** 模式的程式和 app 脫鉤，app 重開後會接回。

## 4. 額度與自動接手

在「設定 → 對話」：

| 設定 | 預設 | 說明 |
|---|---|---|
| 額度用完時自動換帳戶繼續 | 開 | 先找同一種代理的其他訂閱帳戶，以前文節錄接著做 |
| 同種代理都沒有時換別種代理 | 關 | 換到最快重置的其他種代理 |
| 額度重置後自動接著做 | 開 | 換不了帳戶時，等 12 小時內會重置的額度重置後，自動接著做 |

額度恢復後，對話會自動換回原本的帳戶。API 過載（Claude 529、Antigravity 503）或網路瞬斷時，會在提示中倒數，然後自動重試，最多 3 次。

## 5. 排程

頂端「排程」頁列出這台電腦的 Windows 排程：

- **代理建立的**（從對話的指令記錄認出來，可以連回那個對話）、**你納入管理的**、**疑似自己開發的**（執行使用者資料夾裡的腳本，或位在 git repo 裡）會列在前面；系統與廠商的排程預設隱藏。
- 每個排程顯示觸發時間、上次結果、最近 14 次執行，以及接下來 24 小時的時間軸。
- **立即執行、停止、啟用、停用**直接按。**刪除、改時間、改內容**一律「交給代理」：在這個排程自己的管理對話裡，預先填好完整定義與最近的執行紀錄，由你確認後送出。
- 列入管理的排程開始失敗時，會語音與系統通知，並自動請代理診斷（只診斷、不修改；每個排程每 24 小時最多一次）。

### 定時訊息

同一頁的「定時訊息」會在指定的時間把一段文字送進某個對話（或每次開新對話），例如「平日 09:00 整理昨天的錯誤報表」。不需要 Windows 排程，app 開著時才送；錯過的重複訊息只補一次。

對話裡的代理也可以自己建立定時訊息（app 會在給代理的說明裡告訴它怎麼用）：

```
myriagent-schedule add --daily 09:00 -- 要做的事
myriagent-schedule add --weekdays 09:00 --new -- 每次開新對話做的事
myriagent-schedule add --at "2026-12-01 14:00" -- 檢查部署有沒有成功
myriagent-schedule list
myriagent-schedule remove <id>
```

也可以用 `--every 30m` 或 `--cron "0 9 * * 1-5"`。

## 6. 通知

- **系統通知**：代理提問、等待核准、完成或失敗時通知。
- **語音通知**：念一句說明，包括對話標題與這一輪最後一則回覆的第一句、問題或核准說明。可以在「設定 → 一般」調整語速與音調（Windows 語音，優先使用中文語音）。
- **閃爍**：需要你回來看的對話，分頁、標頭與側欄會一直閃，直到你點開它。
- 網頁版與手機也會念同一句（各瀏覽器各自設定開關）。

## 7. 多電腦同步與網頁版

需要先架設 MyriagentHub（[hub-setup.md](hub-setup.md)），並在每台電腦「設定 → 多電腦同步」填入 Hub 網址、完成配對。

- **同步的內容**：帳戶目錄（每台各自登入，憑證不同步）、用量（同一個帳戶只由一台查詢，大家共享結果）、CLI 版本、對話與附件、各電腦的排程摘要、token 計數。
- **其他電腦的對話**在側欄以副本顯示，可以閱讀；這台的權限允許的話，也可以從這台操作它。
- **網頁版**：`https://<你的網域>/app/`，手機與平板都能用。可以看所有電腦的對話、送訊息、核准、回答問卷、停止、上傳附件、看代理產出的圖片與影片、瀏覽工作資料夾，也可以在指定的電腦登入帳戶、安裝或更新 CLI。手機上的麥克風鈕會用系統的語音辨識直接打字。
- **每台電腦自己的政策**（「設定 → 多電腦同步」，只能在本機修改）：
  - 遠端操作：**不接受**、**只能查看**、**可以操作**；也可以逐個對話設定。
  - 允許遠端使用完全自動（預設關）。
  - 允許其他電腦的代理在這台執行指令（預設關）。
  - 遠端操作時在這台通知。
- 伺服器連不上時，桌面照常使用；重新連上後會自動補送。

### 在其他電腦執行指令

被操作的那台打開「允許其他電腦的代理在這台執行指令」之後，對話裡的代理就可以：

```
myriagent-remote list
myriagent-remote run <電腦> [--shell powershell|pwsh|cmd] [--cwd 資料夾] [--timeout 秒] -- <指令>
```

指令在那台以一般使用者權限執行，輸出與結束碼照樣傳回（上限 600 秒）。那台的 app 以系統管理員執行時一律不接受。關機、格式化、改系統設定、需要系統管理員權限這類高風險指令，會在那台跳出置頂的確認視窗，要人在現場同意（3 分鐘沒回應就當成拒絕）。

### 協作人

擁有者可以在「設定 → 協作人」建立協作人的帳號密碼，在對話的「⋯」選單選「協作人…」把對話分享給他。協作人只用網頁版，只看得到分享給他的對話；可以在裡面送訊息、附檔、回答問題與核准工具，但不能改模型、權限、帳戶與資料夾，也看不到儀表板與其他設定。每則訊息都會標出是誰送的。

## 8. 設定一覽

| 分頁 | 內容 |
|---|---|
| 一般 | 主題（深色／淺色／跟隨系統）、字級、動態效果、開機自動啟動、系統匣、系統通知、語音通知 |
| 對話 | Enter 送出、「繼續」鈕的指令、額度用完時的接手方式、Remote Control、跨 CLI 共用、附加給代理的說明 |
| 模型設定 | 每種代理新對話預設的模型、權限模式、推理強度、備援模型 |
| CLI | 各 CLI 的版本、安裝、更新與 CLI 換版時怎麼處理執行中的對話 |
| 多電腦同步 | Hub 網址與配對、同步狀態、遠端操作的政策、已配對的電腦、回收區 |
| 版本與更新 | app 的版本、安裝到這台電腦、自動更新 |
| 協作人 | 建立與管理協作人（需要 Hub） |

設定對話框上方可以搜尋。

### 附加給代理的說明

每個對話開始時，app 會附上一段說明，告訴代理它在這個 app 裡：使用者看得到什麼、要用問卷提問、檔案路徑會顯示成圖片或影片、長時間指令要用 CLI 的背景機制等。可以在「設定 → 對話」改寫，`{cwd}`、`{attachments}` 等變數會自動代換。

## 9. 快捷鍵

| 按鍵 | 作用 |
|---|---|
| Enter／Shift+Enter | 送出／換行（可改成 Ctrl+Enter 送出） |
| Shift+Tab | 切換權限模式 |
| Ctrl+B | 顯示／隱藏側欄 |
| Ctrl+Shift+M | 顯示／隱藏電腦狀態面板 |
| Esc | 關閉選單與對話框；拖曳分頁時取消 |
